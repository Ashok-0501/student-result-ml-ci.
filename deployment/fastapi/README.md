# FastAPI logging service (Practicals 10–11)

This service serves the same trained model generated by `train_model.py` and packaged into the Docker image.

## Local run
From the repository root, first run `python train_model.py`, then:

```bash
pip install -r deployment/fastapi/requirements.txt
uvicorn deployment.fastapi.app:app --host 0.0.0.0 --port 8000
```

## Endpoints
- `GET /` service status
- `GET /health` health check
- `GET /docs` Swagger UI
- `POST /predict` expects attendance, internal_marks, assignment_marks, previous_score (each 0–100)

## Logging
Events are written to stdout. Request IDs and response duration are recorded. Validation failures and runtime exceptions are logged without recording identifiers, tokens, headers, or complete payloads.

## Render
Use the GHCR image built by the Practical-9 workflow: `ghcr.io/ashok-0501/student-result-prediction:latest`. Render image-backed service configuration: PORT=8000 and health path `/health`. A Render dashboard/service and public service URL must be configured by the account owner.
