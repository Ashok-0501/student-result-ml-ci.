# FastAPI logging service (Practicals 10–11)

This service serves the trained model generated by `train_model.py`.

## Local run
From the repository root:

```bash
python train_model.py
pip install -r deployment/fastapi/requirements.txt
uvicorn deployment.fastapi.app:app --host 0.0.0.0 --port 8000
```

## Endpoints
- `GET /` service status
- `GET /health` health check
- `GET /docs` Swagger UI
- `POST /predict` expects attendance, internal_marks, assignment_marks, previous_score (each 0–100)

## Logging and error handling
Events are written to stdout. Request IDs and response duration are recorded. Validation failures and runtime exceptions are logged without recording identifiers, tokens, authorization headers, or complete request payloads.

## Render deployment
The Practical-9 workflow publishes the FastAPI image as `ghcr.io/ashok-0501/student-result-prediction:latest`. Make the GHCR package public or configure registry credentials in Render. Configure the service with port `8000` and health path `/health`. The repository includes a Render Blueprint at the root (`render.yaml`).

A Render account owner must authorize Render, create the service from the Blueprint, and confirm the public service URL. No Render credentials are stored in this repository.
